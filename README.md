# Vocab Flash Cards

Flip-card practice for 4th-grade vocab words built on the roots **graph/gram** (Greek, "write, draw") and **scrib/script** (Latin, "write").

Words: subscribe, grammar, diagram, biography, photograph, telegraph, graph, autograph, script, describe, prescription, manuscript.

Open `index.html` in any browser, or visit the GitHub Pages site.

`vocab-flash-cards-printable.pdf` is a one-sheet, two-sided Letter printout of 15 mini cards (2.5" × 2"). Print two-sided, flipping on the long edge, then cut on the dashed lines.
